🔐 Proteger códigos e observações

Tudo acontece neste aparelho: nada é enviado a lugar nenhum. Cole o resultado na planilha, no lugar do texto puro. Mesmo que alguém consiga ler a planilha, não vê mais o código nem a observação. Texto puro continua funcionando, então dá para proteger só o que importa.

1. Código do médico (hash)

Vale para as colunas observationCode e savedPassword. Com hash, a senha salva não é mais pré-preenchida na tela.

2. Observação do paciente (cifrada)

Vale para a coluna medicalNotes. O código usado aqui precisa ser o mesmo código do médico que deve conseguir abrir.

Atenção: no “modo hackeado” (o erro das 3 tentativas), observações cifradas não são reveladas. Só as de texto puro. Deixe em texto puro o que o erro deve liberar.

3. Link do terminal (abre o sistema já configurado)

Gera um link que grava a URL da API e o token só no navegador de quem o abrir e depois some da barra de endereço (os dados ficam depois do #, parte que nunca vai a servidor nenhum). Use o token de leitura (READ_TOKEN), nunca o do admin. Guarde o link nos favoritos do aparelho do mestre; não compartilhe nem cole em chats públicos.
